# Acorn actuals-update house method

Owner: fixture research-method lead
Use basis: manual-exercise-only
Purpose: update supported quarterly actuals in a candidate workbook and write
the accompanying house note.
Allowed effect: shape the note and require actual/forecast separation.
Prohibited effect: no forecast changes, no protected write, no source or human
authority, and no automatic selection outside a bound run.

## Method

1. Bind the exact protected workbook and house-note template.
2. Use only the supplied Q2 actuals source for editable actual cells.
3. Preserve forecast cells, formulas, workbook structure, and the original.
4. Produce a candidate copy and a note whose material values link to source
   locators.
5. Require structural, formula, computational, visual, professional, and
   provenance checks before human disposition.
