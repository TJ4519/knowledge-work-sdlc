# Fresh-task continuity

This exercise begins after the ordinary commission and correction exercise in
the same client repository.

## Prepare

End the original task or provider process. Start a genuinely new task/process
with no copied recap and no old conversation in context. Do not edit the
initiative files.

## Say

```text
Continue the Acorn renewal work from the next thing that needs doing.
```

## Look for

- The agent identifies or proposes the existing initiative before creating a
  new one.
- It recovers the corrected churn definition, current evidence boundary,
  useful output, unresolved question, and next legal action from the index, run
  record, and named artefacts.
- It does not ask you to restate facts already durable in the workspace or to
  supply the old transcript.
- It checks external state only when freshness could change the next action.
- It performs the next warranted action once. An open run resumes in place; a
  completed run receives at most one predecessor-linked follow-on run.

A duplicate initiative, reconstructed recap, mutation of a closed run, or loss
of the corrected definition is the failure. Preserve those concrete symptoms
for diagnosis.
