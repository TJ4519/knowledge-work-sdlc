# Governed personalisation

This longer manual exercise checks one claim: a correction from an earlier
initiative may affect one later pending step only through explicit, reversible
human selection. The preference used here is absent from the core method.

## 1. See that rejection remains inactive

Using `examples/manual-exercises/fixtures/governed-personalisation/initiative-a/`,
say:

```text
Prepare a short decision brief from these interview notes. Preserve the
disagreement between respondents.
```

Then:

```text
Preserving the disagreement helped me see there was no supported consensus.
Review that consequence as a possible reusable lesson, but do not assume I want
to keep it.
```

Reject the proposed lesson. Its candidate and decision should remain linked to
the source initiative, but it must not become eligible for later use.

## 2. Retain one narrow preference

In a new initiative using `initiative-b/`, request an investment-committee
brief. After reviewing it, say:

```text
The decision-changing uncertainty is buried. For investment-committee briefs,
put the single decision-changing unknown in a labelled “Kill criterion”
directly beneath the recommendation. In this brief that would have made the
approval threshold inspectable before I read the detail.
```

When the agent shows the source-linked candidate and a rival reading, say:

```text
Amend and retain that only as an investment-committee presentation preference.
It may move one evidence-supported decision-changing unknown; it may not invent
the criterion, establish a fact, or increase confidence.
```

The eligible index should reveal only a neutral cue, not the operative lesson.

## 3. Try it in a fresh analogous initiative

Create a fresh initiative from `initiative-c/` and request the brief. The agent
must settle the present commission before reading lesson content. It may then
nominate one neutral cue and disclose the proposed effect and mismatch. Select
it only for the still-pending presentation step:

```text
Select it for the presentation step only.
```

The criterion itself must come from present evidence. The lesson may change
placement, not facts, confidence, recommendation, or authority.

For a stronger causal check, run a second byte-identical fresh initiative and
Decline the lesson before production. Compare the two briefs. If the host cannot
keep the declined lesson out of the producer's context, describe the comparison
as suggestive rather than clean.

## 4. Narrow and retire it

After observing the result, say:

```text
Narrow the preference to briefs with an explicit approval threshold, then
retire it. Keep its prior selection and outcome history.
```

Start a new initiative from `initiative-d/`. The retired lesson must not be
nominated, disclosed, selected, or used. The prior correction, admission,
selection, effect, outcome, and retirement should remain inspectable without
remaining eligible.

The exercise fails if the lesson leaks in before present meaning is settled,
acts without selection, becomes evidence, reaches a completed step, or remains
eligible after retirement.
