# Examples

Examples are teaching and diagnostic material. They are not selected at runtime
and do not carry project or human authority.

- [`expert-extensions/`](expert-extensions/) shows how a lead-owned method can
  adapt professional vocabulary and prompts without narrowing the generic
  core.
- [`manual-exercises/`](manual-exercises/) contains optional prompt sheets and
  small fixtures for experiencing ordinary work, continuation, protected work,
  and governed personalisation in an actual host.

Copy only the material needed for the exercise or import being attempted. The
presence of an example in the source repository never admits it as a project
method, evidence source, policy, or reusable lesson.
