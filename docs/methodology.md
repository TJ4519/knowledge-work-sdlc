# Methodology

## The problem

Most failures in agentic knowledge work are not failures to generate prose.
They are failures to preserve the commission while evidence, interpretation,
tools, specialist work, human decisions, and later corrections cross context
boundaries.

A professional lead should be able to say what they need in ordinary language.
They should not have to translate that need into an internal workflow, remember
which agent ran, or reconstruct yesterday's conversation. The harness therefore
exists to make one transition reliable:

```text
imperfect commission
→ defensible native work product
```

“Defensible” means the work retains enough meaning, evidence, derivation,
challenge, authority, and continuation state for another capable professional
to inspect it, correct it, and continue it.

## The governing function

Choose the smallest mechanism that satisfies the commissioned outcome while
minimising:

- new runtime nouns;
- duplicated semantic authority;
- provider coupling;
- hidden automation of professional judgment; and
- workflow burden placed on the commissioner.

The result conserves a small runtime vocabulary centred on initiatives, runs,
plans, evidence, outputs, challenge, and human disposition. It is not a
case-management system.

## The operating axioms

1. **One main authority.** The main host agent changes posture from concierge
   to orchestrator. A specialist never becomes a second manager.
2. **Artefacts carry work.** A worker reads named durable inputs and writes a
   named durable output. Its chat summary is not the next worker's source.
3. **Semantic judgment stays with the model.** Scripts may scaffold, inspect,
   project, package, or validate mechanical relations. They do not infer the
   commission or select its route.
4. **Human authority remains explicit.** An agent may interpret, recommend,
   challenge, and produce a candidate. It cannot silently approve a material
   meaning, protected write, expert method, or reusable preference.
5. **Evidence follows derivation.** Source entities, retrieval and
   transformation activities, actors/tools, and output claims remain linked.
6. **Continuity is file-native.** A fresh actor rebuilds from the initiative
   index, one run record, and the live output artefacts that record names.
7. **Learning is selected, not absorbed.** Earlier experience can influence a
   later initiative only through a source-linked, human-governed, reversible
   route. A transcript may evidence an episode; provider-native memory never
   becomes project evidence or authority.
8. **Provider claims are empirical.** A plausible manifest, visible tool, or
   passing local validator does not prove native activation or capability.

## The durable representations

```text
AGENTS.md + skills     operating logic
initiative index       identity, focus, status and run pointer
run record             composed plan, rationale, outcomes and gates
output artefacts        durable semantic substance
DESIGN.md               why the system has this shape
```

These files are separate because they answer different questions. Combining
them produces a master summary that duplicates authority; omitting one forces a
future agent to infer state from chat or directory shape.

## The knowledge-work substitutions

Professional work adds four pressures to the initiative/run grammar:

- **Correctable inferred meaning:** preserve the exact commission separately
  from the model's working interpretation.
- **Professional evidence identity:** distinguish literal source content,
  derivation, model interpretation, host observation, and human judgment.
- **Protected native work:** treat a client workbook or template as an exact
  input; work in a candidate copy and require explicit promotion authority.
- **Governed personalisation:** let a consequential correction influence a
  later bounded step only after independent present-intent interpretation and
  explicit human selection.

Expert-owned methods are a fifth product pressure, not a fifth control grammar.
They are immutable project-owned method inputs, curated and bound to a run; they
do not replace the core or activate merely because they were installed.

## Why the pipeline diverges and converges

Every commission converges first on meaning and evidence. It then diverges into
the professional production method appropriate to that commission. It converges
again through challenge, disposition, reconciliation, and continuation.

```text
meaning → evidence → work order
                    ↘ chosen professional production
                     → challenge → human disposition → continuation
```

Not every run needs every method. The run record makes each inclusion,
exclusion, degradation, and gate visible so pruning remains judgment rather
than disappearance.
