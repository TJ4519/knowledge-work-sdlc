# Run record: [run-id]

One accepted intent owns an initiative; one pass through a composed plan owns
one run record at `ai_docs/initiatives/<initiative-id>/run-record/<run-id>.md`.
The same main agent creates this record as concierge and remains its single
writer after changing posture to orchestrator. Update an open or halted record
as the run proceeds; once closed, preserve it and open a successor for new work.
