# Human decision

## Exact evidence
- exact human text and current-turn ID only when directly exposed
- parent/source/delegation/handoff identity separately as transport lineage;
  never substitute it for current-turn provenance
- decision type
- exact target revision and hash
- target kind

## Scope
Protected target, object/time/version/scenario scope, intended use, and expiry or conditions where applicable.

## Semantics
- Confirm: authorises the exact proposed meaning/work order for the named use.
- Use: authorises the exact candidate for the named target/scope/use.
- Reject: rejects that exact revision.
- Amend: requires a superseding revision; it never mutates the target.

## Rule
A model cannot create or broaden this authority.
