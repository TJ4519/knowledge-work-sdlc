# Candidate protected-artifact change descriptor

## Identity and scope
- candidate revision
- supersedes: prior candidate path and hash or none
- settled meaning and work-order revisions, plus any decisions that established them
- protected target, media type, and exact protected scope
- intended use

## Native payload
- payload revision ID, path, media type and byte hash
- full-file or registered delta-applier mode
- promotable: yes/no with reason

## Runtime capability binding
- semantic capability required
- actual host tool or connector used
- actor and observed tool/server version
- observed read/write and authentication scope
- operation-specific probe and result
- permitted operations, fallback or degradation

## Client template binding
- supplied path, exact hash, ownership and revision
- shape-, method-, and policy-bearing roles
- precedence and allowed effect
- editable and protected native objects
- formulas, calculation mode, links, macros, queries, and connections preserved
- structural, formula, computational, visual, professional, and provenance
  checks and results

## Exact changes
For each changed native object record before, after, source/evidence, method,
and dependency consequence.

## Preserved scope
Name protected objects, versions, structures, formulas, formats, automation or
scenarios verified unchanged.

## Validation
Positive, negative, conformance and unchanged-scope checks, results and gaps.

## Source lineage and rival routes
Link evidence and live contradiction.

## Rule
This descriptor is not the protected artefact. Promotion may use only the
separately retained native payload after exact human authority.
