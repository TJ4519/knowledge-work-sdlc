# Deliberate learning catalogue

This is the compact user-governed discovery index, not automatic memory and not
evidence about a new initiative. Full lesson revisions live as immutable files
under `ai_docs/learnings/` so intake never needs to load them.

## Use rule

1. Interpret the current commission before reading lesson content.
2. When a retained lesson appears plausibly relevant, show only its compact
   index row and explain the analogy.
3. Use it only when the user deliberately selects it for a named effect.
4. Link the selection and later outcome from the new initiative's run record.
5. Never let a lesson rewrite the installed method or establish present facts.

## Compact index

| ID | Short label | Scope cue | Status | Source initiative | Lesson file |
|---|---|---|---|---|---|

The ID, label and scope cue may support an analogy after the new initiative's meaning
is recorded. They must not encode the lesson's instruction, factual content or
allowed effect. A row that says what to do has already leaked the lesson before
selection.
