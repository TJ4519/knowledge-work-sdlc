# Optional buy-side company-model support

These four bundled procedures help an analyst specify, produce, challenge and check company-model work. They preserve the difference between company-reported history, an analytical adjustment, a forecast and a scenario, and work alongside the analyst's modelling method and tools.

## Use through the existing SDLC

The main agent starts with knowledge-work, settles the actual commission and records which helpers are warranted in its run. A clear request to use the bundled buy-side skills is sufficient to select these product-supplied helpers for that bounded task; it does not adopt financial assumptions or authorise replacing a protected model. Do not route the installed product's own helper files through expert import merely to use them.

A separate analyst/firm method supplied for import still goes through kw-expert-extension curation, admission and exact run binding. Bundled support cannot override that method, a client template, source restrictions or the user's authority. Where no house method or workbook is supplied, state what is missing and propose a bounded approach or read-only plan; do not invent the missing files or make a template an automatic blocker.

| Procedure | Useful return | Boundary |
|---|---|---|
| derive-buy-side-decision-to-data | A brief connecting the requested model work to sources, permitted changes and important checks | No workbook update or assumption adoption |
| produce-evidence-bound-model-candidate | A candidate change with actual changes, retained inputs, sources and unresolved consequences | No original overwrite or self-approval |
| challenge-frozen-buy-side-candidate | Falsifiable, consequential objections—or no finding | No repair or automatic pass |
| verify-discriminating-buy-side-claims | Source/cell-supported propositions, including baseline checks when there are no objections | No whole-model certificate or forecast validation |

Skills remain one authored corpus; this shared directory holds their common references. In a repository, logical paths beginning .knowledge-sdlc/ resolve at its root. In the plugin, use the managed resource root named by the generated skill binding.

## Workspace requirements

The analyst supplies the workbook, sources and relevant permissions. The host provides source access, calculation tools and any separate reviewer contexts. Bind each check to the proposition and exact candidate it examines. Human adoption and changes to protected originals retain their separate authority.
