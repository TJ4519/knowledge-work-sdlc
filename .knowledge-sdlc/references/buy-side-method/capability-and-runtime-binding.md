# Capability resolution belongs to existing preflight

A check establishes whether this object, operation, account, and role are usable now. It does not certify an entire provider. Do not add a fifth buy-side skill, capability registry, or new service.

Read supplied materials first. After the task is clear, probe only needed operations. At handoff, recheck facts that may differ for the receiving role. Reuse valid observations instead of repeating setup for every cell. Read actual tool schemas; never invent tools or assume parent access transfers to children.

## Distinctions and honest alternatives

| Need | Evidence required | Limitation if absent |
| --- | --- | --- |
| Discover sources | Authorised search reaches relevant material. | Analysis is bounded to supplied sources, not the wider universe. |
| Read exact evidence | Needed original passage/table/context is accessible. | Its contents remain unverified; a summary is not the missing original. |
| Interpret target | Surfaces needed for this particular meaning are visible. | Keep that interpretation provisional or ask for its definition. |
| Inspect formulas | Relevant formulas/dependencies can be read when required. | No formula/downstream-validation claim; value-only work may remain possible. |
| Edit candidate | A separate authorised draft can be produced and revisited. | Return proposed changes, not an edited workbook. |
| Calculate/refresh | The operation executed and its result was inspected. | Label the workbook as uncalculated or incompletely refreshed. |
| Separate contexts | Invocation and history exposure are known at the supported level. | Use a permitted separate human session or report self-review limits. |
| Protect candidate | Existing permissions prevent edits or comparison detects mutation. | Claim procedural protection only; never probe by damaging the original. |
| Retain outputs | Artifacts remain available across the intended handoff. | Export a permitted packet or stop cross-context work, not all useful work. |
| Obtain disposition | An authorised person sees the exact result and conditions. | No model-issued use approval or presumed cross-user custody. |

Formula access is claim-specific. A labelled table may settle one mapping without proving workbook behaviour. Saving an XLSX is not evidence of recalculation. Source interpretation remains agent judgment, not an installed capability proven by a successful ping.

## Permissions and repair

Check permitted sources, data scope, account, and destination. Do not forward restricted research to another provider merely to obtain a reviewer. Use an authorised environment, permitted extract, or manual analyst review.

Do not request credentials in chat or change connectors, entitlements, or organisation settings without authority. For setup instructions, inspect the current official documentation for the actual surface rather than guess its menus.

Distinguish absent/disabled, unauthenticated, wrong account, denied, unsupported, transient, and user-declined operations. Do not repeat an unchanged call after a non-transient failure. One transient retry is the default; more requires changed conditions or user direction. Preserve completed work.

A fallback may change the product or checked scope, not financial meaning. No search does not license remembered numbers. No fresh context does not make self-review independent. No access does not imply no answer exists.

## A small receipt, not another system

Record in the existing run: required operation/object, actual tool or manual route, observation, permission boundary, and resulting limit. The provider binding owns discovery, tool names, context creation, and permissions. This package supplies no tested binding; actual host behaviour and local modifications remain conditions to observe.
