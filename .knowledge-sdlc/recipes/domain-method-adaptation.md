# Domain-method adaptation

Use when the installed method itself—not merely one initiative's output—may be
inadequate. This creates a candidate method change and never edits the active
core or an expert extension automatically.

## Entry bar and causal obligations

Enter only from an explicit method-change commission or an observed failure
linked to the current method revision, a causal hypothesis, and a bounded
evaluation route. “The prompt sounds better” and one successful anecdote are
insufficient.

The run must:

1. locate the failure at the professional method, context selection, provider
   binding, deterministic guard, durable artefact, or human-authority layer;
2. state one candidate change and the observable behavior it predicts;
3. preserve the candidate separately from the active method;
4. include positive, negative, adversarial, and prior-success regression cases;
5. challenge the candidate in a fresh producer-independent context; and
6. stop for exact human Adopt-as-separate-implementation, Amend, or Reject
   authority.

Adoption opens a separately controlled source-change commission. It does not
edit the core, an expert extension, or another run inside this recipe.

```json
  {"id":"prepare-work-order","actor":"agent","method":"work-object-preparer"},
  {"id":"confirm-work-order","actor":"human","optional":true,"trigger":"work order adds consequential scope or method","requires":["work-order"],"provides":["decision"]},
  {"id":"produce-method-candidate","actor":"agent","method":"research-synthesis-producer","provides":["candidate-method"]},
  {"id":"challenge-method","actor":"agent","method":"thesis-challenger","requires":["meaning","evidence-map","candidate-method"]},
  {"id":"adjudicate","actor":"agent","method":"adjudicator","optional":true,"trigger":"material producer-challenger contradiction survives main-agent triage","requires":["challenge","candidate-method"]},
  {"id":"human-disposition","actor":"skill","method":"kw-candidate-disposition","requires":["candidate-method"]}
]
```

Use of a candidate in one initiative does not promote it into the shipped core.
That requires a separate source change and release authority.

Stop without adoption when evidence cannot distinguish the candidate from the
current method, the examples merely encode the preferred answer, or the change
would broaden the method beyond the observed commissions.
